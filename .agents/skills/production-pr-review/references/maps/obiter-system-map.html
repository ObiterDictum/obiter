Review invariant
  • Trace entrypoint to source of truth and derived state.
  • Check organisation, matter, user, cache, object-key, index, artifact, and audit isolation.
  • Search direct dependents of changed contracts and boundaries.
Approval guardrail
  • Do not approve sensitive code if the touched internal flow is unmapped.
  • Do not treat stale map entries as facts without validating current code.
  • Record durable new knowledge in the review repo with synthetic examples only.
